# KIS 외국인 매집 리포트

한국투자증권(KIS) Open API의 **장 마감 후 일별 확정 데이터**를 사용해, 외국인이 지속적으로 순매수하지만 가격은 아직 충분히 반응하지 않은 국내 주식을 매일 순위화합니다.

> 조회·분석 전용입니다. 주문 API와 자동매매 코드는 포함하지 않습니다.

## 매일 나오는 결과

- **오늘 신규매수 검토**: 발견 75점 이상(B등급 이상), 당일 수급·유동성·최소 이력 조건, 분산위험과 가격 게이트를 모두 통과한 종목만 표시한다. 조건을 만족하지 않으면 0개가 정상이다.
- **강한 후보·가격 대기**: 발견 80점 이상(A등급)이지만 가격이 먼저 올랐거나 아직 하락이 진정되지 않은 종목을 매수 후보와 분리한다.
- **오늘 볼 종목 5개**: 신규매수 검토를 먼저 보여주고, 남는 자리를 A등급 가격 대기와 관찰 후보로 채운다.
- **외인 지속 매수**: 최근 10거래일 중 의미 있는 외국인 일별 순매수가 8일 이상인지 본다. 이것은 “20일 누적값이 오른 날 수”와 다른 지표다. 실제 20일 누적선 증감 횟수는 별도로 계산한다.
- 발견등급: `A(80+) → B(75~79) → C(65~74) → 제외`. 절대 순매수 금액은 `500억+` 확인 배지로 쓰고, 메인 순위는 거래대금 대비 강도·최근 수급·매수 지속성을 우선한다.
- 기존 보유·후속 관리 액션은 참고용으로 유지하지만, 메인 리포트의 초점은 신규 후보 발견이다.
- 각 종목의 다음 액션 승격 조건과 신호 무효 조건
- **발견점수** TOP 20과 별도 **오늘 신규매수 검토 / 강한 후보·가격 대기** 순위표
- 20거래일 외국인 누적 순매수 **500억원 이상** 대형 매집 표
- 기존 관심종목과 LG에너지솔루션·LG화학·삼성SDI·한화에어로스페이스·HD현대중공업 고정 관찰
- `매집·눌림 → 매집휴식 → 가격상승 → 수익실현 → 분산·이탈` 단계
- 가격 하락 중 외국인 위험흡수 신호
- 신규매수·추가매수·추격금지·익절·비중축소 액션
- 60일 가격 미니차트, 외국인 5/20/60/120일 누적, 거래량, 실적·목표가
- 모바일 HTML 리포트와 CSV 원자료
- 보유수량·평단·마지막 매수가·매수 차수를 반영한 개인화 액션
- 전체시장 장기 이력 초기화와 주간 워크포워드 백테스트
- 실제 제안 당시의 점수·상태를 보존하고 이후 5·10·20거래일 성과를 자동 갱신하는 실전 누적 평가

생성 파일:

- `reports/latest.html`: 모바일 상세 리포트
- `reports/latest.csv`: 전체 점수 데이터
- `reports/latest.md`: GitHub Actions 요약
- `reports/gate_sweep.md`: 즉시매수 가격 게이트 완화 비교
- `reports/live_evaluation.md`: 배포 이후 실제 추천의 기간별 누적 성과
- `data/history.csv`: 장기 수급·가격 누적 이력
- `data/holdings.csv`: 외국인 실제 보유수량 스냅샷
- `data/signal_runs.csv`: 후보가 0개인 날을 포함한 공식 일일 평가 실행 이력
- `data/signal_snapshots.csv`: 당일 A/B/C 후보와 Shadow 비교군의 변경 불가 스냅샷
- `data/signal_episodes.csv`: 같은 종목의 연속 노출을 묶은 후보 생애주기
- `data/signal_events.csv`: 후보 최초 진입과 신규매수 검토 승격 이벤트
- `data/signal_outcomes.csv`: 다음 거래일 시가 기준 D+5·10·20 성과

## 점수 구조

한 숫자에 모든 의미를 섞지 않습니다.

- `매집강도(0~100)`: 20일 절대 순매수 금액, 거래대금 대비 강도, 매수 지속성, 되팔기 비율, 60·120일 장기 재고, 최근 재가속, 하루 대량거래 집중도를 계산합니다.
- `발견점수(0~100)`: 매집강도, 가격 미반응, 실적·전망, 외국인 보유규모/변화를 묶은 중기 후보 점수입니다. `매집·눌림`·`매집휴식`·`초기반응`은 우대하고 이미 `가격상승`·`수익실현` 단계인 종목과 과도한 급락 종목은 감점합니다.
- `진입 타이밍(0~100)`: 최근 3·5일 외국인 재가속, 3일 가격 반전, 5·10일선 회복, 상승일 거래량, 시장·업종 대비 단기 상대강도와 과열되지 않은 가격경로를 계산합니다. 첫 백테스트에서 점수와 성과가 단조롭게 증가하지 않아 **매수 커트라인이 아니라 순위와 설명용**으로 사용합니다.
- `분산 위험(0~100)`: 외국인 1·3일 매도, 누적 되팔기, 갭·반등 강도, 윗꼬리, 수급 집중도로 수익실현 가능성을 표시합니다.
- `기존 진입점수(0~100)`: 매집강도에 가격 미반응·가격/거래량 구조·실적을 더하고 단기 과열을 차감하는 비교용 점수로 보존합니다.
- `진입준비`: 점수와 별개로 `진입가능`, `반전확인`, `눌림대기`, `재가속확인`을 판정합니다. 높은 점수도 이 게이트를 통과하지 못하면 **즉시매수** 액션으로 승격되지 않습니다.
- `오늘 신규매수 검토`: 발견 75점 이상이면서 기존 엄격 가격 게이트를 통과한 종목입니다. A등급(80+)을 우선하고 B등급(75~79)은 보조 검토로 봅니다. 65~74점은 가격 게이트를 통과해도 관찰로만 남깁니다.
- `강한 후보·가격 대기`: 발견 80점 이상이지만 가격 게이트를 통과하지 못한 종목입니다. 좋은 종목과 좋은 매수가격을 한 목록에서 섞지 않습니다.
- `오늘 볼 종목`: 위 두 상태를 우선한 뒤 사람이 확인할 관찰 후보를 채웁니다. 급락·이벤트·당일 데이터 미수신 종목은 제안에서 제외합니다.
- `종합점수`: 기존 모델과 비교 및 점수 이력 연속성을 위해 함께 보존합니다.

20거래일 외국인 누적 순매수가 500억원 이상이면 `500억+` 신호를 부여합니다. 이 값은 확인 배지이며 메인 정렬 키가 아닙니다. 후보 순서는 거래대금 대비 외인 순매수, 최근 1·3·5일 수급, 매수일 지속성, 되팔기 비율과 발견점수를 우선합니다.

| 구성 | 배점 | 핵심 판단 |
|---|---:|---|
| 외국인 매집 | 40 | 순매수 **금액**, 거래대금 대비 강도, 매수일 지속성, 하루 이틀 매도 후 되팔기 비율, 장기 재고 |
| 가격 미반응 | 25 | 시장·업종 대비 가격 반응, 눌림/압축, 조건부 위험흡수 |
| 가격·거래량 구조 | 15 | 유동성, 변동성, 거래량 확인, 과열·구조 훼손 여부 |
| 실적·전망 | 20 | 영업이익·순이익·ROE, KIS 증권사 목표가 컨센서스 |
| 기관 보조 | ±5 | 기관 수급은 독립 신호가 아니라 확인용 가감점 |

연속 매수일만 세지 않습니다. 최근 20일 중 매수일·중립일·매도일을 구분하고, 매도 금액이 앞선 매수 금액의 얼마를 되돌렸는지 계산합니다. 따라서 하루 이틀 매도하더라도 장기 재고와 순매수 강도가 유지되면 `매집휴식`으로 처리할 수 있습니다.

매집 국면은 `지속매집`, `장기매집·휴식`, `장기매집·재가속`, `신규재진입`, `상승진행`, `손바뀜·재확인`, `기관주도·외인확인`, `이상대량·확인`, `분산·이탈`로 나눕니다. 기관 주도 상승과 소수 대량거래는 외국인 지속매집에 섞지 않습니다.

증권사 목표가는 기준일 이전 120일 자료만 사용하고, 보고서 수·최신성·목표가 편차에 따라 전망 점수를 중립값으로 축소합니다. 오래된 단일 목표가나 편차가 큰 컨센서스가 신규매수 점수를 과도하게 올리지 못하게 합니다.

단계 판정은 시장·업종 상대수익률뿐 아니라 가격이 올라온 **경로**도 같이 봅니다. 1·3·5·10·20일 수익률, 최근 10·20일 저점 대비 반등률, 20일 이동평균 대비 이격, 저점 이후 상승거리의 ATR 배수, 최근 5·10일 상승일 수와 연속 상승일, 반등 거래량 증가율, 20일 고점 접근도를 계산합니다. 특히 `현재가 ÷ 최근 20일 최저가 - 1`이 15% 이상이면 20일 종가 수익률이 낮아도 `상승진행`으로 전환해 신규 추격을 막습니다. 수익실현 판단은 5일 누적이 아닌 당일 외국인 수급을 사용합니다.

가격 하락 + 외국인 매수는 다음 조건을 함께 통과할 때만 긍정적인 `위험흡수`로 인정합니다.

- 거래대금 대비 외국인 순매수 강도가 충분함
- 60일 가격 구조가 심하게 훼손되지 않음
- 영업이익 등 최소 실적 필터 통과
- 누적된 외국인 보유수량이 확인되는 경우 감소하지 않음

20일 25% 이상 급락하거나 정상 가격제한폭으로 설명하기 어려운 단일 가격변동이 발견되면 `이벤트확인`으로 격리합니다. 권리락·분할·합병·중대한 악재 여부를 확인하기 전에는 신규매수를 제안하지 않습니다.

## 액션 기준

| 액션 | 기본 조건 |
|---|---|
| 오늘 신규매수 검토 | 발견 75점 이상, 당일 수급·유동성·최소 이력 통과, 분산위험 25점 이하, `지속매집`/`장기매집·재가속`, 아래 V2 가격 게이트 통과 |
| 모델 진입 게이트(호환) | 발견 65점 이상부터 계산하지만 65~74점은 메인 신규매수 제안이 아니라 관찰로 표시 |
| 급락 멈춤 확인 | 최근 3일 수익률이 -3% 미만이라 아직 하락 가속 중 |
| 첫 눌림 대기 | 20일 수익률 +3% 이상 또는 20일 저점 대비 +5% 이상 반등 |
| 관찰 | 진입 52점 이상 또는 기존 종합 64점 이상 |
| 첫 눌림 대기 | 장기 분산 뒤 `신규재진입`했지만 최근 가격이 먼저 급등 |
| 외국인 확인 대기 | 기관 주도 상승 또는 장기매집 중 최근 외국인 휴식 |
| 블록·이벤트 확인 | 하루 대량거래 집중도가 높고 매수 지속성이 약함 |
| 보유 시 분할 추가매수 | 마지막 매수가 대비 3% 이상 하락하고 외국인 3·5일 순매수, 1·3일 가격 안정, 분산위험 25점 이하를 재확인한 경우 |
| 추격 금지·보유 | 매집이 이미 가격상승 단계로 전환 |
| 절반 익절·잔여 추적 | 상승 뒤 외국인 수익실현 확인 |
| 비중 축소·신규매수 금지 | 외국인 이탈·분산 단계 |

갭 상승 기준은 `5%`와 `1.2 × ATR` 중 큰 값을 사용합니다. 장 마감 데이터에서 외국인 매도와 윗꼬리가 확인되면 총 50~75% 익절 검토로 강화합니다.

`강한 신규매수`는 첫 워크포워드 감사에서 고득점과 성과의 단조 관계가 확인되지 않아 비활성화했습니다. **현재 성공확률과 기대값은 순위표에서 숨깁니다.** 확률 보정은 단순 표본 수가 아니라 전체·시간 홀드아웃의 양(+) 기대값, 비용 반영 손익분기 승률, 점수대 순서까지 모두 통과해야 활성화됩니다.

리포트의 메인 순서는 종합점수 순이 아니라 실행 가능성 순입니다. 보유정보가 없는 종목의 익절 액션은 실행 지시로 표시하지 않으며, 추가매수 큐는 `portfolio.csv`에 등록된 실제 보유종목만 대상으로 합니다.

## 개인 보유정보 반영

`data/portfolio.csv`에 실제 보유정보를 입력하면 신규종목과 보유종목의 액션을 구분합니다.

```csv
symbol,quantity,average_price,last_buy_price,tranche_count
068270,50,185000,180000,2
```

- 기본 신규 진입 제안액: 1,000만원
- 기본 추가매수 제안액: 500만원
- 마지막 매수가 대비 3% 이상 하락해도 바로 추가하지 않고 외국인 3·5일 순매수와 가격 하락 진정을 다시 확인
- 추가매수 간 최소 3거래일 간격
- 최대 4차까지 제안

모두 `config.toml`에서 변경할 수 있으며 실제 주문은 실행하지 않습니다.

## 실전 추천 누적 평가

백테스트와 별도로, 일일 KIS 스캔에서 **그날 실제로 제안한 결과**를 배포 이후부터 보존합니다. 저장된 과거 데이터에 현재 모델을 다시 적용해 신호를 소급 생성하지 않으므로 완전한 아웃오브샘플 기록으로 사용할 수 있습니다.

- A/B/C 후보를 모두 저장해 75점 기준의 유효성을 비교합니다.
- 55~64점 근접 탈락 종목은 `near_miss` Shadow 코호트로 전수 저장합니다.
- 55점 미만 적격 종목은 KOSPI/KOSDAQ과 시가총액 대·중·소 구간별로 주 1회 회전하는 `matched_control` 대조군을 구성합니다. 기본값은 구간별 2종목입니다.
- Shadow 종목은 메인 리포트·텔레그램·이메일 추천에 노출하지 않고 누적 평가 파일에서만 비교합니다.
- 같은 종목이 연속으로 노출되면 하나의 에피소드로 묶어 반복 추천을 독립 표본으로 세지 않습니다.
- Shadow 종목이 A/B/C 정식 후보로 올라오면 `candidate_promotion` 이벤트를 남겨 승격 이후 성과를 별도로 평가합니다.
- 후보에서 `episode_gap_sessions` 거래일 이상 이탈한 뒤 재등장하면 새 에피소드가 시작됩니다.
- `강한 후보·가격 대기 → 오늘 신규매수 검토`의 최초 승격은 별도 평가 이벤트로 기록합니다.
- 신호 다음 거래일 시가를 진입가로 사용하고 D+5·10·20 수익률, 비용 후 수익률, 같은 시장 중앙값 대비 초과수익률, 최대 상승·낙폭, 목표·손절 선도달을 갱신합니다.
- 동일 신호일 재실행은 최초 공식 스냅샷을 덮어쓰지 않습니다. 당시 모델 버전과 점수 설정 해시도 함께 남깁니다.
- 오래된 원자료가 보존기간을 지나 제거돼도 이미 판정된 성과는 유지합니다.

`reports/live_evaluation.md`는 정식 후보·근접 탈락·매칭 대조군의 D+5·10·20 비용 후 수익률과 시장초과수익을 나란히 보여줍니다. 이를 통해 추천 종목의 오탐뿐 아니라 낮은 점수로 놓친 종목의 미탐도 확인할 수 있습니다.

표본이 적을 때 모델을 자동으로 바꾸지는 않습니다. 최소 20~30개 에피소드에서는 오류 유형을 점검하고, 60~100개 이상의 독립 에피소드가 쌓인 뒤 등급·게이트 조정 여부를 검토합니다.

## GitHub 설정

### 1. KIS 키 등록

저장소에서 `Settings → Secrets and variables → Actions → New repository secret`으로 들어가 다음 두 Secret을 만듭니다.

| Name | Secret |
|---|---|
| `KIS_APP_KEY` | KIS 앱키 |
| `KIS_APP_SECRET` | KIS 앱시크릿 |

키를 코드, 이슈, Actions 변수(Variables)에 넣지 마세요. 반드시 **Secrets**에 저장합니다.

투자자 순매수 금액은 KIS 응답의 단위가 달라져도 수량×가격과 대조해 원 단위로 자동 보정합니다. 보정 결과가 비정상적이면 잘못된 점수표를 저장하지 않고 실행을 실패 처리합니다.

호출 제한을 바꾸려면 같은 화면의 `Variables` 탭에 `KIS_CALLS_PER_SECOND`를 추가합니다. 기본값은 초당 5회입니다. 호출 제한 오류가 반복되면 `2` 또는 `1`로 낮춥니다.

### 2. 첫 실행

1. 저장소의 `Actions` 탭
2. `Daily foreign-flow report`
3. `Run workflow`
4. 처음에는 `universe_limit`을 `30`, `skip_backfill`을 체크하여 연결 테스트
5. 성공하면 `universe_limit`을 비우고 `skip_backfill`을 해제해 전체시장 일일 스캔
6. 최초 한 번은 `full_history_bootstrap`을 체크해 전체시장의 약 6개월 이력을 초기화

전체 최초 실행은 시장 1개월을 스캔하고 상위 후보의 약 6개월 이력을 채우므로 평소보다 오래 걸립니다. 이후에는 최근 데이터를 합쳐 누적합니다.

`full_history_bootstrap`은 전체 종목에 여러 번 API를 호출하므로 최초 1회만 실행합니다. 실행 시간이 길거나 호출 제한 오류가 발생하면 저장소 Variable `KIS_CALLS_PER_SECOND`를 `2`로 낮추고 다시 실행합니다.

리포트는 실행 화면의 `Summary`, `Artifacts`에서 확인할 수 있고 성공 후 저장소의 `reports/latest.html`에도 저장됩니다.

### 3. 텔레그램·이메일 전송(선택)

둘 다 선택입니다. 하나만 넣어도 되고, 둘 다 넣으면 같은 브리핑이 같이 갑니다. Secret이 없어도 리포트 생성은 정상 작동합니다.

텔레그램:

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 받을 채팅 ID |

이메일(SMTP, Gmail 앱 비밀번호·네이버·아웃룩 등):

| Name | Secret |
|---|---|
| `EMAIL_SMTP_HOST` | 예: `smtp.gmail.com` |
| `EMAIL_SMTP_USER` | SMTP 로그인 계정 |
| `EMAIL_SMTP_PASSWORD` | SMTP 비밀번호 또는 앱 비밀번호 |
| `EMAIL_TO` | 받을 주소. 여러 개는 쉼표로 구분 |
| `EMAIL_FROM` | 선택. 없으면 `EMAIL_SMTP_USER` |
| `EMAIL_SMTP_PORT` | 선택. 기본 587, SSL이면 `465` |

465 포트를 쓰면 SSL로 연결합니다. 본문은 오늘 볼 종목 요약이고, 상세 HTML 리포트를 첨부합니다.

## 실행 일정

GitHub Actions가 평일 **20:35 KST**에 실행됩니다. 18시대는 당일 외인 확정 데이터가 아직 안 나오는 경우가 많아서, 20:30 이후로 늦췄습니다. GitHub 예약 실행은 혼잡 시 몇 분 늦어질 수 있습니다. 컴퓨터를 켜둘 필요가 없습니다.

`Weekly walk-forward backtest`는 토요일에 실행됩니다. 과거 시점의 정보만 사용해 신호 다음 거래일 시가에 진입하고 이후 20거래일을 평가합니다. 후보 발견은 `discovery_v2`, 실제 진입은 기존 V1·가격게이트·V2(기존 추가매수)·현재 `flow_price_v2`를 나란히 비교합니다. 현재 V2는 외국인 수급을 핵심으로 유지하되 상승·수익실현 단계는 신규 발견 순위에서 제외하고, 단일 타이밍 점수 커트라인 대신 가격 게이트를 사용합니다. `+8% 목표`와 `-6% 손절` 선도달 평가 외에 사용 전략도 근사합니다: 1천만원 최초 진입, 마지막 매수가 대비 3% 하락 시 외국인 3·5일 순매수와 가격 안정까지 재확인한 뒤 500만원 추가(최대 4차·최소 3거래일 간격), 5% 갭 상승 시 절반 익절, 잔여분 8% 추적손절. 모든 체결은 신호 다음 날 시가를 사용하고 왕복 비용 0.3%를 반영합니다. 종목 수익률뿐 아니라 같은 시장의 중앙값 대비 **초과수익률**도 함께 기록합니다. 최소 판정 300건, 시간 홀드아웃 75건, 전체·홀드아웃 양(+) 기대값과 양(+) 초과수익, 비용 반영 손익분기 승률, 점수대 순서가 모두 통과되기 전에는 확률 보정을 활성화하지 않습니다.

수동 로컬 실행:

```bash
python -m pip install -e ".[dev]"
export KIS_APP_KEY="..."
export KIS_APP_SECRET="..."
python -m kis_flow_bot smoke
python -m kis_flow_bot run --universe-limit 30 --skip-backfill --no-notify
# API를 호출하지 않고 저장된 전체시장 데이터로 점수·리포트만 즉시 재계산
python -m kis_flow_bot rerank --no-notify
# 저장된 이력으로 즉시매수 게이트만 바꿔 비교
python -m kis_flow_bot gate-sweep
```

모델이나 설정이 바뀌면 `Recalculate action report` 워크플로가 저장된 데이터로 자동 재계산합니다. 따라서 점수식 수정 확인을 위해 전체 KIS 스캔을 다시 기다릴 필요가 없습니다.

일일 수집 성공률이 허용 범위 안이더라도 개별 종목의 최신 수급이 누락될 수 있습니다. 리포트 기준일과 종목 `as_of`가 다르면 해당 종목은 관찰표에 남을 수는 있어도 신규매수 제안에는 들어가지 않습니다. 실전 리포트와 워크포워드 백테스트는 같은 유동성·최소 이력·데이터 신선도 정책을 사용합니다.
