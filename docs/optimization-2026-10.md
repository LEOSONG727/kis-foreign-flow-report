## 실제 데이터 비교

기준 커밋: `40b5ee34dba8e37dffd119a84be2fb7901bd9b76`.

- `history.csv` 463,545행, 피처 1,232종목.
- 같은 입력의 기존 피처 전부가 값·타입까지 정확히 일치했다. 신규 `foreign_net10`만 추가됐다.
- 같은 재무 캐시·상태·보정값으로 비교한 점수 및 액션 포함 기존 177개 컬럼도 정확히 일치했다.
- 같은 프로세스에서 순차 측정한 피처 계산: 기존 **16.55초 → 9.98초**, 약 **40% 단축**. 로컬 1회 측정으로, API 수집과 전체 주간 분석 시간의 개선율을 의미하지 않는다.
- 별도 프로파일에서도 함수 호출 수가 약 7,027만 → 3,412만으로 줄었다.
- 전체 저장 데이터의 알림 없는 rerank 및 HTML/Markdown/CSV 생성을 검증했다. 원본 추천 스냅샷과 과거 성과 장부는 덮어쓰지 않았다.

10월 16일 저장 순위에 동일한 점수로 표시만 다시 적용하면, 기존 숏리스트에 섞였던 CJ·삼성에스디에스(`제외`)가 빠지고 적격 대기·관찰 종목이 채워진다. SK텔레콤에는 20일 +920억과 함께 60일 -6,140억·120일 -8,686억을 표시한다. 단기 재유입은 장기 지속매집의 증거와 구분한다.

일요일 갱신된 재무 캐시로 전체 rerank를 수행하면 금요일에 저장된 보고서와 후보 수가 달라질 수 있다. 동일 입력으로 코드 변경 전후를 비교해야 최적화 영향과 데이터 갱신 영향을 분리할 수 있다.

## 검증과 운영 범위

GitHub 최초 최종 검사에서 267개 테스트는 통과했지만, pandas 2.3.3 + NumPy 2.5.4 조합이 날짜 연산마다 경고를 내어 총 725,572건이 기록됐다. [NumPy 2.5의 generic timedelta 폐기 안내](https://numpy.org/doc/stable/reference/arrays.datetime.html)와 [pandas 이슈 #66608](https://github.com/pandas-dev/pandas/issues/66608)에 근거해, pandas 2.x를 사용하는 동안 NumPy 상한을 `<2.5`로 제한한다. 이 특정 경고는 pytest에서 오류로 처리해 재발을 감지하며, 경고를 숨기지 않는다. Jev의 nullable boolean 필터 순서도 결과를 유지하면서 수정해 기존 다운캐스팅 경고를 제거한다.

`tests/test_runtime_and_selection.py`는 일시 장애 복구, 반복 장애의 호출 상한, 인증/한도 중단, 부분 저장과 미수집 재개, 거래일·당일 수집률, 제외 종목 재유입, 장기 순매도 표시를 검사한다. 기존 PIT·모델·백테스트·리포트 회귀도 함께 실행한다.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest
python -m kis_flow_bot rerank --no-notify
```

실제 KIS/DART API를 수정 후 이 환경에서 다시 호출하지 않았으며, 전체 주간 연구도 재실행하지 않았다. DART의 누락된 과거 자료를 복원하거나 미래 수익을 보장하는 변경은 아니다. 최신 연구에서 학습 도전자의 Top-5 초과수익 평균은 -0.81%로 승격 기준을 통과하지 못했다. 기존 승격 제한, PIT 격리, Jev 유료 호출 중지는 유지한다.
